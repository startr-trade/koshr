**koshr** is an open-source, self-hostable git server that stays git-compatible for existing
tooling, with verified identity, row-level access control and signed, non-repudiable mutations.

koshr is a tool, not a service. Hosting is offered only through [Provr](https://provr.dev), which
runs released koshr unchanged.

## Status

Not released yet: there is nothing to install. The work is planned on the
[koshr board](https://github.com/startr-trade/koshr-board).
